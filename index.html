해석 원칙

Go / Console 분리: 동일 모델도 제공 방식마다 가격·제한·학습·보존 정책이 다릅니다. Console은 OpenCode 직접 제공 카탈로그(기존 Zen)를 뜻하며 임의의 외부 provider 전체 목록은 포함하지 않습니다. 공식 deprecated 항목은 활성 목록에서 제외합니다.

Console 무료: 한시적 무료의 종료일·요청 한도가 미공개이면 Unknown / Not stated로 표시합니다. 무료 DeepSeek V4.1 Flash는 별도 ID이며 Go ZDR 종료일을 적용하지 않습니다. Console의 US/EU 표시는 공식 Console 전체 정책이며 개별 upstream·정확한 처리 지역은 미공개입니다.

Est. Cost: input 1M + output 200K 토큰의 단순 합산 예시이며 한 번의 1M-context 요청 견적이 아닙니다. 표는 기본 짧은-context 구간을 표시하고 추가 구간은 상세에 표시합니다. 캐시·카드 수수료는 제외합니다. Console 카드 수수료는 충전 건당 4.4% + $0.30입니다.

Go 사용 한도는 모델별 월간 달러 한도로 공개됩니다. 각 모델에서 5시간 한도는 월간 한도의 20%, 주간 한도는 50%, 월간 한도는 100%입니다. 예를 들어 월 $60 모델은 $12 / $30 / $60이고, 월 $15 모델은 $3 / $7.50 / $15입니다.

Monthly limit은 OpenCode가 공식 문서에 공개한 모델별 포함 사용량입니다. 모델 간 혼합 사용의 내부 회계 방식은 공식 문서에 없는 내용을 임의로 추정하지 않습니다.

Req / mo는 OpenCode의 일반적 Go 요청 패턴을 기준으로 한 공식 예상치입니다.

서드파티 코딩 에이전트는 OpenCode의 최신 안내에 따라 안정적인 세션 ID를 전달해야 라우팅과 프롬프트 캐싱을 최적화할 수 있습니다.

프로모션은 기본 Monthly limit/요청 수와 분리해 추적하며, 활성 기간에는 dashboard가 공식 promotional 값을 우선 표시합니다.

중국계 모델과 중국 전송은 별개입니다. 개발사 국적만으로 호스팅 지역이나 데이터 전송을 추정하지 않습니다.

Unknown은 보수적으로 미확인 상태를 뜻합니다. 서로 다른 harness의 벤치마크를 단일 숫자 순위로 합산하지 않습니다.
