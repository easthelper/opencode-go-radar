Usage / mo는 OpenCode Go 공식 표의 모델별 포함 사용량입니다. 전체 계정 한도는 5시간 $12 / 주 $30 / 월 최대 $60이지만, 모델에 따라 실제 포함 Usage는 $15·$30·$60으로 다릅니다.

GLM-5.3-Flash 2× 프로모션은 별도 배지로 표시합니다. 공식 Usage 표에는 기본 $15가 기재되어 있어, 프로모션의 유효 dollar cap을 임의로 $30으로 환산하지 않습니다.

중국계 모델과 중국 전송은 별개입니다. 개발사 국적만으로 호스팅 지역이나 데이터 전송을 추정하지 않습니다.

Unknown은 보수적으로 미확인 상태를 뜻합니다. 서로 다른 harness의 벤치마크를 단일 숫자 순위로 합산하지 않습니다.
