해석 원칙

Go quota는 모델별 독립 지갑이 아니라 공유 풀입니다. 계정 기준 한도는 5시간 $12 / 주 $30 / 월 $60입니다.

Effective / mo의 $15·$30·$60은 OpenCode가 공개한 모델별 실효 raw usage입니다. 월 $60 공유 quota 기준으로 보면 각각 대략 4× / 2× / 1× quota burn에 해당합니다. 따라서 $15 모델을 다 쓴 뒤 다른 $15 모델에서 새 $15가 생기지 않습니다.

Req / mo는 해당 모델만 사용한다고 가정한 OpenCode의 일반적 요청 패턴 기준 예상치입니다.

GLM-5.3-Flash 2× 프로모션은 별도 배지로 표시합니다. 공식 Usage 표에는 기본 $15가 기재되어 있어 프로모션의 유효 dollar cap을 임의 환산하지 않습니다.

중국계 모델과 중국 전송은 별개입니다. 개발사 국적만으로 호스팅 지역이나 데이터 전송을 추정하지 않습니다.

Unknown은 보수적으로 미확인 상태를 뜻합니다. 서로 다른 harness의 벤치마크를 단일 숫자 순위로 합산하지 않습니다.
